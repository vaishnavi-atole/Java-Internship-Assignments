# Student Portal Application

## Overview
This is a simple Angular application developed to demonstrate Angular fundamentals such as Components, Routing, Forms, and Services.

## Features
- Home Page
- Student List
- Add Student Form
- Angular Routing
- Service-Based Data Sharing
- Component-Based Architecture

## Technologies Used
- Angular 21
- TypeScript
- HTML
- CSS

## Project Structure

src/app
├── components
│   ├── home
│   ├── student-list
│   ├── add-student
│   ├── navbar
│   └── student-details
├── services
│   └── student.ts
├── models
│   └── student.ts

## Setup Instructions

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project

```bash
cd student-portal
```

3. Install dependencies

```bash
npm install
```

4. Run the application

```bash
ng serve
```

5. Open in browser

```text
http://localhost:4200
```
