# Library Management System

## Objective
Develop a Library Management System using Java OOP concepts, Collections Framework, Exception Handling, and Java 8 features.

## Features
- Add Book
- Add User
- Issue Book
- Return Book
- Search Book by Title
- Display All Books
- Display Available Books
- Display Issued Books

## Technologies Used
- Java
- OOP (Object-Oriented Programming)
- ArrayList
- HashMap
- Exception Handling
- Java 8 Streams API
- Lambda Expressions

## Project Structure
```
src
├── com.library
│   ├── Main.java
│   ├── model
│   │   ├── Book.java
│   │   └── User.java
│   ├── service
│   │   └── LibraryService.java
│   ├── service_impl
│   │   └── LibraryServiceImpl.java
│   └── exception
│       ├── BookNotFoundException.java
│       ├── UserNotFoundException.java
│       └── BookAlreadyIssuedException.java
```

## How to Run
1. Open the project in Eclipse IDE.
2. Run `Main.java`.
3. Use the menu options to perform library operations.
